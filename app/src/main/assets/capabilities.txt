FILE XPLORER · v0.2

FILES
Phone, tablet and Android desktop-window layouts; local/shared storage and persisted SAF folders (SD/USB/document providers); two panes on wide screens; copy, move, create, rename, select, permanent delete, built-in image/video viewers and sharing/external viewers for other formats; favorites, recents, sorting and hidden files. No silent overwrites. Editors keep backups in private cache. Background tasks stop if Android terminates the process; they are not persistent transfer services.

APPEARANCE / MEDIA
System, Light glass and Dark glass themes on phone/tablet/Android windows. Search in the mobile bottom dock; Copy/Move/Paste above it. Shared rounded glass menus, forms, confirmations, editors, file rows, navigation and progress windows. Modal backgrounds blur the underlying activity using RenderEffect on Android 12+; Android 8–11 use a downsampled blurred snapshot. Native cross-window background blur is also requested on Android 12+ where supported. Main glass surfaces sample a blurred decorative scene; they do not refract arbitrary foreground content. Built-in image/video controls sample and blur the displayed media behind them. Animations can be disabled and honor Android's animator setting.
Images: static preview (GIF displays its first frame), fit, pinch zoom (1–8×), pan, 90-degree rotation and sharing. Large images are decoded down to a 4096-pixel maximum edge to control memory. Video: play/pause, seek, ±10 seconds, mute, speed presets and sharing; Android device codecs determine playback support. Playback pauses on lost focus; no background playback or subtitle library is included. App-owned viewers are styled; external Android apps and system permission/root-manager screens control their own UI.

SEARCH
Recursive names/folders; case and regex; plain text content in UTF-8/UTF-16; extension, size and date filters; current folder or accessible sources; cancellation; skipped-location count; 5,000 result cap. Content search scans at most 50 MB per file, ignores binary files and uses the RE2 linear-time regex engine (no lookbehind or backreferences), plus a per-match time budget. Content is matched in chunks of up to 64K characters; matches spanning a chunk boundary are not guaranteed. Unreadable/protected locations cannot be searched without the required grants. SAF results can reveal the granted tree; exact parent navigation is provider-dependent.

ARCHIVES
Read/extract: ZIP/APK/JAR, 7z (including password-protected archives where supported by the library), TAR, compressed TAR, GZIP, BZIP2, XZ/LZMA streams, CPIO/AR and legacy RAR4. RAR5, WIM, CAB, DMG, Zstandard and proprietary archive codecs are not included. Create: ZIP (optional AES-256), 7z/LZMA2, TAR, TAR.GZ, TAR.XZ, TAR.BZ2. 7z creation does not encrypt. ZIP entry add/replace/delete creates a backup first; modified APKs need a new signature. Archive previews are limited to 128 MB per entry. Extraction refuses path traversal and links, and limits expanded data to 32 GiB. Integrity tests stream the supported archive data; ISO tests validate structure rather than a nonexistent file CRC.

DISK IMAGES
Create ISO9660 + Joliet, read/browse/extract ISO9660/Joliet, convert single-track 2352-byte Mode 1 or Mode 2 Form 1 BIN data to 2048-byte ISO. Joliet file names are limited to 64 UTF-16 code units. Individual ISO files above 4 GiB and multi-extent ISO are not supported. No UDF, audio CD, mixed-mode CUE, NRG, DAA, UIF, DMG, MDF/MDS or proprietary conversion. Read-only loop mounting/unmounting is a root tool and depends on kernel/filesystem support. Optical-disc burning, Windows virtual-drive emulation and bootable-USB writing are not implemented.

APK / DEX
APK metadata and signature inspection, decoded read-only binary manifest view, ZIP package entry editing, DEX class/method index, DEX-to-smali and smali-to-DEX, APK signing with an on-device Android Keystore key, and installed-app APK/split export. Device-key signing is not the original publisher's identity. The first DEX in an APK is selected by the quick action; extract additional classesN.dex entries to inspect/edit them separately. No ARSC recompilation, Java decompilation, binary XML recompilation, signature-check bypass, resource obfuscation, APK cloning or split-package installer.

EDITORS
Text and hex editing up to 2 MB; find/replace with optional regex; atomic replacement for local files where supported; backups in cache. UTF-8 and UTF-16 are recognized. Binary XML decoding is an inspection view, not an editable build round trip.

ROOT
Android/data and Android/obb shortcuts appear on the overview, in the mobile overflow menu, in tablet locations and in Settings. These shortcuts request su and carry root transport into all subfolders. Uses su only after explicit enablement. Browse/copy/edit with root transport; shell, chmod/chown, read-only image loop mount and unmount. This app does not root a device. Android/data, system partitions, SELinux, read-only filesystems and mount support remain controlled by Android and the root manager. Root operations have not been exercised on a rooted device. Shizuku transport is not included in this version.

NETWORK / PARITY
No network-storage clients, cloud accounts, Wi-Fi transfer server or remote synchronization are included. This is an original native file-manager build, not complete MT Manager / 7-Zip / PowerISO feature parity. Check each supported format above rather than assuming another product's full feature set.
